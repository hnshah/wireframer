## How these compose

Wireframer owns product interpretation, object modeling, task flow, interaction-model choice, screen minimization, state coverage, and the canonical rubric.

Impeccable is useful for later critique, distillation, hardening, interaction detail, and visual refinement.

Anthropic's frontend design skill is a downstream high-fidelity visual-design pass.

Figma-specific skills should own native canvas execution and design-system mechanics.

Load specialist guidance when the stage calls for it. Keeping every design reference in context all the time can dilute the product-design task.
